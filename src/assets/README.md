# assets

Images and SVGs used by the portfolio (e.g. a profile photo or custom icons
that Lucide doesn't cover).

- `riyad.png` — the original photo (1122×1402, ~2 MB). Not imported anywhere.
- `riyad.jpg` — a resized copy (1200px tall, ~240 KB) made from it with
  `sips -Z 1200 -s format jpeg -s formatOptions 80 riyad.png --out riyad.jpg`.
  This is the one the WelcomeCard shows; regenerate it if the PNG changes.
